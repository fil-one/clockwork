# Next.js development

Before writing code, read the relevant guide in `node_modules/next/dist/docs/`,
resolved from this directory. Use the installed version's APIs and conventions,
and heed deprecation notices.

These instructions are maintained by the repository. Keep `agentRules: false`
in the Next.js configuration so `next dev` leaves source files unchanged during
release qualification. Do not wrap these instructions in Next.js managed-block
markers: Next.js 16.4 removes those blocks when `agentRules` is disabled.
