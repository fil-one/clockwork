# Clockwork Commerce

Standalone commerce platform foundation for the approved product behavior in
`commerce_platform_spec.md`. It uses Node 24, pnpm 10, Turborepo, strict
TypeScript, Next.js/Vercel, Supabase/Postgres with Drizzle, WorkOS AuthKit,
Hono/OpenAPI, Trigger.dev, Stripe, immutable S3 evidence, and React PDF.

Start with `docs/foundation-handoff.md`. The preserved product specification
remains controlling; ADRs record the fixed greenfield architecture and
implementation conventions supplied with the foundation assignment.
